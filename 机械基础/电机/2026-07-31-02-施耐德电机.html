施耐德电机

2026-08-03
编辑本页

重要参数

频率

这些参数告诉变频器你的电机规格,必须正确设置:

  • BFR (9613) - 电机标准频率: 50Hz (中国标准)，电机在额定工作状态下的供电频率，它是电机设计的基准点

同步转速 = 120 × 频率 / 极对数
4极电机：50Hz → 1500 rpm 同步转速 (实际约1400-1450 rpm，考虑滑差)

设置过低 → V/f 比偏大 → 电机过励磁 → 发热、饱和、效率低
设置过高 → V/f 比偏小 → 电机欠励磁 → 转矩不足、带载能力差

  • 性质: 配置参数，设置一次后基本不改
  • 作用: 告诉变频器"我的电机是什么规格

控制

实际运行时，你通过以下方式控制输出频率（从而控制转速）：

1. 模拟量控制 (最常用)

通过 AI1-AI5 模拟输入给定频率：

模拟输入信号        →  输出频率     →  电机转速
0-10V (或 4-20mA)   →  0-50Hz      →  0-1400rpm

例如：
5V    → 25Hz  → 约700rpm
10V   → 50Hz  → 约1400rpm
  • FR1 (8413) = AI1模拟输入 (选择控制源)
  • LSP (3105) = 0 Hz (最低速度)
  • HSP (3104) = 50 Hz (最高速度)

2. EtherCAT/Modbus 通信控制

通过网络发送目标频率：

配置参数:

  • CD2 (8424) = Modbus通信 (或 EtherCAT)
  • 通过通信协议写入目标频率寄存器

3. 预设速度 + 数字输入

设置几个固定速度，通过数字开关切换：

DI1 = OFF, DI2 = OFF  →  低速 (10Hz)
DI1 = ON,  DI2 = OFF  →  中速 (25Hz)
DI1 = OFF, DI2 = ON   →  高速 (50Hz)

4. 面板键盘控制

直接在变频器面板上设置目标频率。

FR给定频率通道

FR1 决定了变频器从哪里获取目标频率（速度给定）
这是一个"信号源选择器"，告诉变频器："听谁的指令来控制输出频率"

FR2 - 第二频率通道
可以配置多个频率源，通过逻辑切换：

  • 正常运行用FR1（通信控制）
  • 紧急情况切到FR2（本地电位器）

CD 命令通道分配

CD1 决定了变频器从哪里接收控制命令（启动/停止/方向等）
这是一个"命令源选择器"，告诉变频器："听谁的命令来启动、停止、正反转"

参数 作用 控制内容
FR1 (8413) 频率给定通道 电机转多快 (目标速度)
CD1 (8423) 命令通道 启动/停止/运行方向 (开关控制)
  1. CD1发送"启动"命令 → 电机开始运行
  2. FR1给定"30Hz" → 电机以30Hz频率运行

概念

飞车重启

飞车重启是指：变频器在电机已经旋转的状态下上电或启动，自动捕捉电机当前转速和相位，然后平滑接管控制，而不是强行从零开始输出导致电流冲击或跳闸。
假设电机正以 1000 rpm 反转，变频器不知情，直接按 0 rpm 起动：

电机反电动势 ←──────  ──────→ 变频器输出
              冲突！
              ↓
           瞬时电流 > 200%
              ↓
         OCF 过流跳闸

常见错误码

故障码 含义 常见原因
ObF DC bus overvoltage 减速太快、制动电阻未接
OHF Motor overheating 电机参数错、长时间过载
OCF Overcurrent 加速太快、负载突变
PHF Phase loss 输入缺相、输出接触不良
CnF Communication fault SM2 watchdog（你已解决）
InF Internal fault 硬件故障

问题处理

进入OP但是不可以控制

现象：

  • 驱动器卡在 Switch on disabled 状态 (statusword 0x50)
  • 收到正确的控制字 (CMD=6) 但不响应状态转换
  • 错误码从 0x6100 变为 0x5100
  • 速度始终为 0

根因（已定位）： 从 data.pdf 参数文件发现：

  • FR1 (给定频率通道1) = 默认 AI1模拟输入（模拟量输入端子）
  • CD1 (命令通道1) = 默认 端子排（物理端子）
  • 当前驱动器不从 EtherCAT 接收命令和速度，而是从物理接线端子获取
