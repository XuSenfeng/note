# storage服务

定义了 Flipper Zero 的 **Storage(存储)服务**。它是固件里最核心的系统服务之一,负责统一管理设备上所有的文件系统读写

它是所有文件操作的**统一抽象层**,主要职责:

**管理两种物理存储**

- `/int` — 内部 Flash 存储(设备内置,容量小, 现在是SD卡的隐藏目录)
- `/ext` — 外部 SD 卡(可插拔,容量大)
- `/any` — 自动选择(优先 SD 卡,回退到内部)
- `/data`、`/assets` — App 专属的数据/资源目录

```c
#define STORAGE_INT_PATH_PREFIX        "/int"
#define STORAGE_EXT_PATH_PREFIX        "/ext"
#define STORAGE_ANY_PATH_PREFIX        "/any"
#define STORAGE_APP_DATA_PATH_PREFIX   "/data"
#define STORAGE_APP_ASSETS_PATH_PREFIX "/assets"
  
#define INT_PATH(path)        STORAGE_INT_PATH_PREFIX "/" path
#define EXT_PATH(path)        STORAGE_EXT_PATH_PREFIX "/" path
#define ANY_PATH(path)        STORAGE_ANY_PATH_PREFIX "/" path
#define APP_DATA_PATH(path)   STORAGE_APP_DATA_PATH_PREFIX "/" path
#define APP_ASSETS_PATH(path) STORAGE_APP_ASSETS_PATH_PREFIX "/" path
```

统一的文件/目录操作接口:打开、读、写、关闭、创建、删除、遍历目录等， 它作为一个独立服务运行,其他 App 通过消息队列(record 系统,`RECORD_STORAGE "storage"`)向它发请求,由服务串行处理。这样多个 App/线程并发访问存储时不会冲突

通过 PubSub 机制广播事件: SD 卡挂载/卸载/挂载出错、文件关闭、目录关闭等。其他模块可以订阅这些事件做出反应(比如 UI 显示"SD 卡已插入")


## 使用

Storage 是一个系统 record,任何 App 通过 record 系统拿到它:

```c
Storage* storage = furi_record_open(RECORD_STORAGE);  // 打开
// ... 使用 storage ...
furi_record_close(RECORD_STORAGE);                     // 用完必须关闭
```

### 文件操作


| 函数                                            | 作用              |
| --------------------------------------------- | --------------- |
| `storage_file_alloc(storage)`                 | 分配 File 句柄      |
| `storage_file_open(file, path, access, open)` | 打开/创建文件         |
| `storage_file_read(file, buff, n)`            | 读 n 字节,返回实际读取数  |
| `storage_file_write(file, buff, n)`           | 写 n 字节,返回实际写入数  |
| `storage_file_seek(file, offset, from_start)` | 移动读写位置          |
| `storage_file_size(file)`                     | 文件大小            |
| `storage_file_eof(file)`                      | 是否读到文件末尾        |
| `storage_file_close(file)`                    | 关闭文件            |
| `storage_file_free(file)`                     | 释放句柄(会自动 close) |
常用的mode 
- 读:`FSAM_READ` + `FSOM_OPEN_EXISTING`
- 写(新建/覆盖):`FSAM_WRITE` + `FSOM_CREATE_ALWAYS`
- 追加:`FSAM_WRITE` + `FSOM_OPEN_APPEND`
### 目录操作

|函数|作用|
|---|---|
|`storage_dir_open(file, path)`|打开目录|
|`storage_dir_read(file, &info, name, len)`|读下一个条目(遍历)|
|`storage_dir_close(file)`|关闭目录|
### 通用操作

这部分的操作不需要使用flie句柄即可直接操作文件

| 函数                                   | 作用                             |
| ------------------------------------ | ------------------------------ |
| `storage_common_stat`                | 获取文件/目录信息                      |
| `storage_common_mkdir`               | 创建目录                           |
| `storage_common_remove`              | 删除(目录需为空)                      |
| `storage_common_rename`              | 重命名/移动                         |
| `storage_common_copy`                | 复制文件                           |
| `storage_common_fs_info`             | 查询总容量/剩余空间                     |
| `storage_file_exists(storage, path)` | 文件是否存在                         |
| `storage_dir_exists(storage, path)`  | 目录是否存在                         |
| `storage_simply_mkdir`               | 建目录(已存在也算成功)                   |
| `storage_simply_remove`              | 删除                             |
| `storage_simply_remove_recursive`    | 递归删除(目录非空也行)                   |
| `storage_get_next_filename`          | 生成不重复的文件名(如 cookies、cookies1…) |
- `storage_file_get_error(file)` — 取错误码
- `storage_error_get_desc(err)` — 错误码转文字描述

### 示例
+ 读文件
```c
Storage* storage = furi_record_open(RECORD_STORAGE);
File* file = storage_file_alloc(storage);

if(storage_file_open(file, EXT_PATH("test.txt"),
                     FSAM_WRITE, FSOM_CREATE_ALWAYS)) {
    const char* text = "Hello Flipper\n";
    storage_file_write(file, text, strlen(text));
}

storage_file_close(file);   // 即使 open 失败也要 close
storage_file_free(file);
furi_record_close(RECORD_STORAGE);
```
+ 写文件
```c
Storage* storage = furi_record_open(RECORD_STORAGE);
File* file = storage_file_alloc(storage);

if(storage_file_open(file, EXT_PATH("test.txt"),
                     FSAM_READ, FSOM_OPEN_EXISTING)) {
    uint8_t buffer[64];
    size_t read = storage_file_read(file, buffer, sizeof(buffer));
    // 处理 buffer 里的 read 字节
}

storage_file_close(file);
storage_file_free(file);
furi_record_close(RECORD_STORAGE);
```
+ 遍历目录
```c
File* dir = storage_file_alloc(storage);
if(storage_dir_open(dir, EXT_PATH("myapp"))) {
    FileInfo info;
    char name[256];
    while(storage_dir_read(dir, &info, name, sizeof(name))) {
        // name 是条目名;info.flags & FSF_DIRECTORY 判断是否为子目录
    }
}
storage_dir_close(dir);
storage_file_free(dir);
```
