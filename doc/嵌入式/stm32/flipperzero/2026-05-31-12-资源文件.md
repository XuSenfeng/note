# 资源文件

## 资源文件

### 图片资源

将放到**应用目录**下的某个子文件夹中
#### 单个图片

在配置文件里面添加

```python
fap_icon_assets="images",  # Image assets to compile for this application
```

构建后，`fbt` 会自动生成：
- `{APPID}_icons.h`
- `{APPID}_icons.c`
并把图片转换成 `Icon` 符号：
- 单张图片文件名会生成 `I_` 前缀
- 例如 `AssetDolphin_71x25.png` -> `I_AssetDolphin_71x25`

```c
extern const Icon I_AssetDolphin_71x25;
```
  
在代码里这样使用：
  
```c
#include <{APPID}_icons.h>
canvas_draw_icon(canvas, 4, 18, &I_AssetDolphin_71x25);

// 也可以使用添加组件
widget_add_icon_element(app->widget, 4, 18, &I_AssetDolphin_71x25);
```

#### 动画资源
动画资源不是一个单独的 png，而是一个目录。
目录里需要有：
  
- 多帧图片：`frame_0.png`、`frame_1.png` ...
- 帧率文件：`frame_rate`

- `images/AssetAlarm_47x39/frame_0.png`
- `images/AssetAlarm_47x39/frame_1.png`
- `images/AssetAlarm_47x39/frame_2.png`
- `images/AssetAlarm_47x39/frame_3.png`
- `images/AssetAlarm_47x39/frame_4.png`
- `images/AssetAlarm_47x39/frame_rate`
构建后会生成动画 `Icon` 符号：
```c
extern const Icon A_AssetAlarm_47x39;
```
  
可以看到，动画资源会生成 `A_` 前缀。
```c
typedef struct {
	IconAnimation* animation;
	bool running;
} DemoAnimModel;

// 绘制下一帧的图像
static void demo_anim_draw(Canvas* canvas, void* model_) {
	DemoAnimModel* model = model_;
	canvas_clear(canvas);
	// 进行绘制
	canvas_draw_icon_animation(canvas, 40, 20, model->animation);
}

// 处理输入
static bool demo_anim_input(InputEvent* event, void* context) {
	App* app = context;
	  
	if((event->type != InputTypeShort) || (event->key != InputKeyOk)) {
		return false;
	}
  
	bool should_start = false;
	with_view_model(
		app->animation_view,
		DemoAnimModel * model,
		{
			model->running = !model->running;
			should_start = model->running;
		},
		true);
	  
	if(should_start) {
		icon_animation_start(app->animation);
	} else {
		icon_animation_stop(app->animation);
	}
	  
	return true;
}

// 进入界面的回调函数
static void demo_anim_enter(void* context) {
	App* app = context;
	  
	with_view_model(
		app->animation_view, 
		DemoAnimModel * model, 
		{ model->running = true; }, 
		true);
	// 开始动画刷新的时钟
	icon_animation_start(app->animation);
}
  
static void demo_anim_exit(void* context) {
	App* app = context;
	  
	icon_animation_stop(app->animation);
	with_view_model(
	app->animation_view, DemoAnimModel * model, { model->running = false; }, false);
}
  
static void demo_anim_init(App* app) {
	app->animation_view = view_alloc();
	app->animation = icon_animation_alloc(&A_AssetAlarm_47x39);
	  
	view_allocate_model(app->animation_view, ViewModelTypeLocking, sizeof(DemoAnimModel));
	with_view_model(
		app->animation_view,
		DemoAnimModel * model,
		{
			model->animation = app->animation;
			model->running = false;
		},
		false);
	// 配置回调函数
	view_set_context(app->animation_view, app);
	view_set_draw_callback(app->animation_view, demo_anim_draw);
	view_set_input_callback(app->animation_view, demo_anim_input);
	view_set_enter_callback(app->animation_view, demo_anim_enter);
	view_set_exit_callback(app->animation_view, demo_anim_exit);
	view_tie_icon_animation(app->animation_view, app->animation);
}
```

- `IconAnimation` 负责“当前播到第几帧”
- `View` 负责“这个页面怎么画、怎么响应按键”
- `Model` 负责“这个页面当前状态是什么”，这里主要是 `running`
- `view_tie_icon_animation()` 负责把“动画帧变化”和“页面刷新”连起来
  
按运行顺序看，这套流程是：  
1. `icon_animation_alloc()` 创建动画对象。
2. `view_allocate_model()` 给动画页面分配 model。
3. `view_set_draw_callback()` 注册绘制函数，里面用 `canvas_draw_icon_animation()` 画当前帧。
4. `view_tie_icon_animation()` 把动画对象绑定到 view，动画每跳一帧就会触发页面刷新。
5. 切到这个页面时，`enter callback` 调用 `icon_animation_start()`，定时器开始推进帧。
6. 定时器每 tick 一次，动画切到下一帧，view 收到刷新通知后重新 draw。
7. 按 `OK` 时切换 `running`，再决定调用 `icon_animation_start()` 还是 `icon_animation_stop()`。
8. 离开页面时，`exit callback` 停止动画并把状态复位。

> `view_allocate_model()` 负责“给 View 挂一块状态内存”  
   `with_view_model()` 负责“安全地读写这块状态内存”, 实际就是在一个保护资源的锁里面执行这部分的代码, 最后的参数为true的时候会调用界面的刷新
### 文件资源

由 `application.fam` 里的 `fap_file_assets="files"` 开启：

它和 `fap_icon_assets` 的区别是：
- `fap_icon_assets`：把图片编译进代码，变成 `Icon` 符号
- `fap_file_assets`：把文件打进 FAP，运行时解包到 app 的资源目录
运行时访问时不要写死路径，推荐用：
```c
APP_ASSETS_PATH("docs/readme.txt")
APP_ASSETS_PATH("config/demo.ini")
```

```c
// 把文件里面的内容读取出来, 追加在output字符串里面, 并在前面加上标题和路径

static void asset_use_append_file(
	Storage* storage,
	FuriString* output,
	const char* path,
	const char* title) {
	Stream* stream = file_stream_alloc(storage);
	FuriString* line = furi_string_alloc();
	  
	furi_string_cat_printf(output, "[%s]\nPath: %s\n", title, path);
	if(file_stream_open(stream, path, FSAM_READ, FSOM_OPEN_EXISTING)) {
		while(stream_read_line(stream, line)) {
			furi_string_replace_all(line, "\r", "");
			furi_string_replace_all(line, "\n", "");
			furi_string_cat(output, furi_string_get_cstr(line));
			furi_string_cat(output, "\n");
		}
		file_stream_close(stream);
	} else {
		furi_string_cat(output, "Failed to open file.\n");
		FURI_LOG_E(TAG, "Failed to open asset file: %s", path);
	}
	  
	furi_string_cat(output, "\n");
	furi_string_free(line);
	stream_free(stream);
}

// 请求使用文件资源
Storage* storage = furi_record_open(RECORD_STORAGE);
asset_use_append_file(
	storage,
	app->file_text,
	APP_ASSETS_PATH("docs/readme.txt"),
	"docs/readme.txt");
asset_use_append_file(
	storage,
	app->file_text,
	APP_ASSETS_PATH("config/demo.ini"),
	"config/demo.ini");
furi_record_close(RECORD_STORAGE);
```
## 官方资源

### 添加动画

在asset文件夹里面保存各种动画的配置文件
动画分为三种

- blocking - 用于阻塞系统通知的关键动画。打包为 `assets_dolphin_blocking.[h,c]`。
- internal - 用于海豚空闲动画的内部动画。转换为 `assets_dolphin_internal.[h,c]`。
- external - 用于海豚空闲动画的外部动画。打包到资源文件夹并放在 SD 卡上。

#### 配置文件

##### manifest.txt

包含随机动画选择的动画枚举, 海豚的起点

```bash
# 固定的文件头
Filetype: Flipper Animation Manifest
Version: 1

# Animation 1
# 动画名称。必须与动画目录名完全一致
Name: L0_NoDb_128x51
# 此动画对应的 Dolphin `butthurt` 值范围
Min butthurt: 0
Max butthurt: 0
# 此动画对应的 Dolphin 等级范围。如果为 `0`，则该动画不会参与随机待机动画选择，
# 只能通过精确名称选中
Min level: 0
Max level: 0
# 该动画在随机选择时被选中的概率权重
Weight: 0

# Animation 2
Name: L0_SdBad_128x51
Min butthurt: 0
Max butthurt: 0
Min level: 0
Max level: 0
Weight: 0

```

##### meta.txt

按顺序播放的 Flipper Format 文件

```bash
# 固定头部
Filetype: Flipper Animation
Version: 1

# 动画宽度，单位为像素
Width: 128
Height: 51
# 播放一次的动画的位图帧数量
Passive frames: 6
# 循环的动画帧的数量
Active frames: 0
# 位图帧的播放顺序，其中前 N 帧是播放一次，后续 M 帧是循环状态。
# 顺序中的每个数字 X 都对应一个位图帧，其文件名为 `frame_X.bm`。
# 该文件必须存在。任意 X 都可以重复，以便在动画中引用同一帧
Frames order: 0 1 2 3 2 1

# N 个循环帧在完整主动周期中的重复次数。例如，如果主动周期帧是 `6` 和 `7`，
# 并且 `Active cycles` 为 `3`，那么完整循环周期会播放 `6 7 6 7 6 7`。
Active cycles: 0
# 每秒播放的帧数
Frame rate: 2
# 单个动画总播放时长
Duration: 0
# 进入循环之前的暂停时间
Active cooldown: 0

# 显示文字的序号
Bubble slots: 0
```
