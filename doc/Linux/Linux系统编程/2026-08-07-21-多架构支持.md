# 多架构支持
[官方手册](https://linuxkernel.org.cn/doc/html/latest/admin-guide/binfmt-misc.html)
可以通过要打开文件的特性来选择到底使用哪个程序来打开。比Windows更加强大的地方是，它不光光可以通过文件的扩展名来判断的，还可以通过文件开始位置的特殊的字节(Magic Byte)来判断

如果要使用这个功能的话，首先要绑定binfmt_misc，可以通过以下命令来获取ARM的执行容器
```bash
docker run --privileged --rm tonistiigi/binfmt --install arm64
```
**在当前宿主机上注册 ARM64 架构的二进制模拟支持**，让你的机器能够运行 ARM64 架构的程序 / Docker 镜像
> 给容器最高特权，因为需要往宿主机内核注册 `binfmt_misc` 处理规则
> 容器执行完就自动删掉，不留垃圾
> 一个专门用来安装 QEMU 用户态模拟器的轻量镜像
> 只使用ARM64的

这个容器实际 

- **把 QEMU 模拟器二进制文件复制到宿主机**（挂载了宿主机文件系统）
- **往 `/proc/sys/fs/binfmt_misc/` 写注册规则**（通过 `--privileged` 拿到权限）
