# 滤波

## 一阶线性滤波
```
 y[n] = y[n-1] + alpha * (x[n] - y[n-1])
```

使用上一次的汇报值, 加上alpha参数乘以当前值和上一次数值的差值

```
y[n] = (1-α)·y[n-1] + α·x[n]
```


这是从**连续一阶低通**导出的。连续一阶低通的微分方程是：

```
τ·dy/dt + y = x        τ 是时间常数
```

对 `y` 做拉普拉斯变换得传递函数：

```
H(s) = 1 / (1 + s·τ)
```

**-3dB 截止角频率**：`ωc = 1/τ`，所以 `fc = ωc / 2π = 1/(2π·τ)`。

现在把它离散化，用**后向欧拉**近似导数：

```
dy/dt ≈ (y[n] - y[n-1]) / dt
```

代入微分方程：

```
τ·(y[n]-y[n-1])/dt + y[n] = x[n]
y[n]·(1 + τ/dt) = x[n] + (τ/dt)·y[n-1]
```

解出 `y[n]`：

```
y[n] = (τ/dt)/(1+τ/dt) · y[n-1]  +  1/(1+τ/dt) · x[n]
```

对比 EWMA 的 `(1-α) · y[n-1] + α · x[n]`，令：

```
α = 1/(1 + τ/dt)
```

把 `τ = 1/ωc` 代进去，分子分母同乘 `ωc·dt`，记归一化量 `ω = ωc·dt = 2π·fc·dt`：

```
α = 1/(1 + τ/dt)
  = (dt/τ) / (1 + dt/τ)
  = (ωc·dt) / (1 + ωc·dt)
  = ω / (1 + ω)
  
ω = α/(1-α)
```

| dt            | α=0.5 的等效 fc |
| ------------- | ------------ |
| 5ms (200Hz)   | 31.8Hz       |
| 10ms (100Hz)  | 15.9Hz       |
| 2.5ms (400Hz) | 63.7Hz       |

## 卡尔曼滤波

假设**状态噪声**与**观测噪声**符合**高斯分布；**
通过**观测数据** 对 **状态量** 进行**最优估计。**
### 计算公式
卡尔曼滤波法的核心问题是：如何建立滤波所需的**状态方程**和**观测方程**。在实际工作过程中，卡尔曼滤波法将为系统提供最优估计，其前提是系统应具备线性模型 ，使用卡尔曼滤波法可以简化计算量，并且节数据存储
